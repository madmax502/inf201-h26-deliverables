# Use of Generative AI

We used AI as a support tool while working on Deliverable 2.

- **Understanding the task:** We asked questions about the regular expression in Task 1 and discussed how to make file reading more robust, including a check for missing files.
- **Interpreting the reports:** We discussed whether refunds and cancelled transactions should be included in hourly totals. We kept the sum of all transaction prices as requested in the assignment and documented that it is not net revenue.
- **Formatting and comments:** We used AI to clean up the code so that it follows PEP8, structure the notebook with Markdown, and add short comments in selected places.
- **Reviewing correctness:** AI identified and corrected the NOK currency mask, changed refund ratios to use transaction counts rather than revenue, and added the required output formats and filenames.
- **Checking and preparing the submission:** AI helped run and check the notebook, update requirements, summarise the results.
- **Repository documentation:** We used AI for suggestions for the README and `.gitignore`. We also used useful code-completion suggestions from github while writing the code.


## Collaboration

We meet in person and write the code together on one computer. Both group
members contribute to solving the tasks. Because we use one computer and Git
account, the commits are recorded under one person even though the work is shared.
