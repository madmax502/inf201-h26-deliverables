# INF201 H26 Deliverables

Pair deliverables for INF201 Advanced Programming at NMBU, autumn 2026.

**Authors:** Max Carl Andresen and Sam Mirtaheri

## Contents

Each deliverable has its own folder with a Jupyter notebook containing the code, results and discussion.

| Folder | Topic |
|---|---|
| `Deliverable_1/` | Weather data for Ås from the Norwegian Meteorological Institute (frost.met.no): temperature, precipitation, historical comparison, heatwaves and moving average |
| `Deliverable_2/` | Campus Coffee Shop sales pipeline: reading register logs with mixed encodings, regex parsing, recursion, NumPy outlier cleaning and pandas reports. Input data is generated with `generate_data_for_d2.py` |
